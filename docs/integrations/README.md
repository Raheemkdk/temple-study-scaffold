# Integration boundaries

The **weekend implementation target** is a user-supplied Temple Canvas iCalendar feed and browser Web Push. Google Calendar API, Apple Calendar access, and SMS remain documented options. Calendar export or synchronization is not required to send app-controlled Web Push.
